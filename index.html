Dev Server Required for Direct Disk Writes

Because web browsers restrict direct file system writes from file:/// URLs, running the built-in CLI server enables seamless 1-click updates to your repository.

2. Open http://localhost:3000.
3. Clicking Sync to Source Code will now instantly write to disk and rebuild!
