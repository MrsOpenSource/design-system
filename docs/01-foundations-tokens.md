# Enterprise Design System Framework
## Volume 1: Design Tokens & Foundations Architecture

---

### 1. Architectural Overview & 3-Tier Token Strategy

To maintain scalability across multi-device enterprise applications (Laptop, Tablet, Mobile) and ensure instant themeability (allowing placeholder colors and fonts to be cleanly replaced later), this system implements a strict **3-Tier Design Token Hierarchy** complying with the **W3C Design Tokens Community Group (DTCG)** standard.

```
┌────────────────────────────────────────────────────────┐
│  Tier 1: Global Reference Primitives (primitives.json)  │
│  - Raw palette hexes (#2563EB, #F1F5F9, etc.)          │
│  - Mathematical spacing scale (4px, 8px, 12px, etc.)   │
│  - Raw typography scales (12px, 14px, 16px, etc.)      │
│  - Motion durations, border radii, base shadows        │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  Tier 2: Semantic / System Tokens (semantic.json)      │
│  - Meaning-based abstraction: surface.card, text.brand │
│  - Dark / Light / High-contrast mode bindings          │
│  - Status indicators (success, warning, danger, info)  │
│  - AI-Specific Semantics (ai.accent, ai.shimmer, etc.) │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  Tier 3: Component-Scoped Tokens (*.tokens.json)       │
│  - kpiCard.metric.fontSize, dataTable.row.height       │
│  - genAi.composer.borderFocus, chatBubble.user.radius  │
│  - Density modifiers (compact, comfortable, spacious)  │
└────────────────────────────────────────────────────────┘
```

### 2. Placeholder System: Typography & Color Decoupling

#### 2.1 Color Substitution Guide
All components consume Tier 2 (`sys.color.*`) or Tier 3 (`component.*`) tokens. **No component ever references raw hex values directly.**
When replacing colors in the future:
1. Update `tokens/primitives.json` under `color.brand.placeholder-primary` (50–950) with your organizational brand palette.
2. Update `color.brand.placeholder-secondary` (50–950) with secondary brand or accent hues.
3. Update `color.neutral` (0–1000) with your slate, zinc, or warm gray palette.
4. Update `color.ai-special` for custom AI sparkle/glow styling (e.g., enterprise purple, electric violet, or corporate cobalt).
5. All downstream components (KPI cards, Data tables, Charts, Gen AI prompt boxes) automatically inherit the new identity without rewriting component code or Figma layouts.

#### 2.2 Typography Substitution Guide
All typography styles consume semantic definitions:
- `typography.font-family.sans`: Set to clean enterprise system UI stacks (`system-ui, -apple-system, Segoe UI, Roboto, Helvetica Neue, sans-serif`). Replace with custom brand sans-serif (e.g., Inter, Segoe UI Variable, San Francisco, Roboto) when ready.
- `typography.font-family.display`: Dedicated heading font stack for high-impact dashboards and KPI figures.
- `typography.font-family.mono`: Dedicated monospace stack for prompt inputs, model reasoning traces, code snippets, and tabular financial/metric values.

Enterprise dashboards and Gen AI interfaces require precise vertical alignment and tabular figures.

| `kpi.metric-standard` | 24px | 28px (1.16) | 600 Semibold | Secondary KPI metric / card value |

| `heading.h4` | 18px | 24px (1.33) | 500 Medium | Modal headers, group titles |
| `body.large` | 16px | 24px (1.5) | 400 Regular | Conversational AI responses, intro paragraphs |

> [!IMPORTANT]
> **Numeric Tabular Guarantee**: All dashboard metrics, KPI figures, table numbers, and countdown timers must apply `font-variant-numeric: tabular-nums` (or CSS OpenType feature `'tnum' on`). This ensures that figures align vertically without horizontal jitter when live metrics stream or refresh.

### 4. Spacing, Rhythm & Spatial Geometry

The system is built on an immutable **4px / 8px linear grid scale**:

$$\text{Spacing}(n) = n \times 4\text{px}$$

- `spacing.0` (0px): Reset
- `spacing.1` (2px): Micro-spacing, sparkline dot offset, hairline border alignment
- `spacing.2` (4px): Inner badge padding, icon-to-label gaps
- `spacing.3` (6px): Compact table row vertical padding
- `spacing.4` (8px): Base increment, button horizontal padding (compact), input icon offset
- `spacing.6` (12px): Standard form element gap, mobile card padding
- `spacing.8` (16px): Card interior padding (compact), mobile margin
- `spacing.10` (20px): Table cell padding (comfortable)
- `spacing.12` (24px): Standard card padding, dashboard widget grid gap
- `spacing.16` (32px): Laptop page margin, section divider
- `spacing.20` (40px): Large dashboard section spacing
- `spacing.24` (48px): Page bottom safe margins
- `spacing.32` (64px): Hero layout gutters

### 5. Surface & Elevation System

Enterprise dashboards require clear visual separation between background canvas, analytic cards, and temporary overlay layers (drawers, modals, AI popups).

```
Level 0: Canvas (sys.color.surface.canvas) -> Background behind all widgets (#F8FAFC)
Level 1: Cards & Panels (sys.color.surface.card) -> KPI Cards, Charts, Tables (Shadow: shadow.sm)
Level 2: Hovered Cards & Sticky Headers (Shadow: shadow.md)
Level 3: Dropdowns, Menus, Popovers (sys.color.surface.elevated) (Shadow: shadow.lg)
Level 4: Flyout Drawers & Sidebars (Shadow: shadow.xl)
Level 5: Center Modals & System Alerts (Shadow: shadow.2xl)
Special AI Level: AI Ambient Glow (shadow.ai-glow-subtle) & Active Glow (shadow.ai-glow-focused)
```

### 6. Motion & Micro-Interactions Framework

| Motion Token | Duration | Cubic Bezier Curve | Purpose |
|---|---|---|---|
| `motion.instant` | 50ms | `linear` | Direct tooltips, checkbox toggles |
| `motion.fast` | 150ms | `cubic-bezier(0.2, 0, 0, 1)` | Button press, dropdown menu expand, table row hover |
| `motion.normal` | 250ms | `cubic-bezier(0.2, 0, 0, 1)` | KPI card flip, drawer slide-in, modal scale-up |
| `motion.slow` | 400ms | `cubic-bezier(0, 0, 0.2, 1)` | Chart transition, multi-page tab switch |
| `motion.ai-cursor` | 800ms | `ease-in-out` (infinite) | Gen AI streaming cursor blink |
| `motion.ai-shimmer`| 1500ms | `linear` (infinite) | AI "Thinking..." reasoning accordion shimmer |

### 7. Iconography Framework

- **Standard Grid**: Icons are authored on a 24×24px bounding box with a 2px inner safety margin.
- **Render Sizes**:
  - `icon.xs` (14×14px): KPI delta arrows, table sort indicators.
  - `icon.sm` (16×16px): Inline input adornments, button icons, citation pills.
  - `icon.md` (20×20px): Sidebar navigation, card header actions.
  - `icon.lg` (24×24px): Modal header icons, empty-state hero symbols.
  - `icon.xl` (32×32px): AI sparkle hero, large upload triggers.
- **Stroke Weights**: Uniform 1.75px for normal density; 1.5px on compact desktop density.
- **AI Icon Set**: Includes dedicated glyphs for `sparkles`, `wand`, `bot-avatar`, `branch-diverge`, `thought-bubble`, `thumbs-up-check`, and `stop-circle`.
